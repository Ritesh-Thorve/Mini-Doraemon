# Mini-Doraemon

A personal portfolio for Me, a security researcher focused on web application security, Android security, and bug bounty research. The site brings together research projects, technical blog posts, and vulnerability disclosures.

It also includes two browser-based research tools: **Recon Launcher** opens public-source searches for a domain, while **Dork Launcher** runs selected domain search queries across supported search engines. These tools help organize public-information gathering; they do not scan or test a target directly.
